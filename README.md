# VKPerformance Car Apps

This branch contains the two Vincare applications published through the MGU Store source:

- **PERFORMANCE** — live engine data, road-estimate dyno, and guarded exhaust-valve controls.
- **Climate Control** — a climate status display for BMW HU_MGU / iDrive 7.

The source also keeps the shared runtime, build tools, and renderer/controller components these apps require. The separate upstream app packages are not part of this branch's MGU Store catalogue.

BMW OAP SDK files, vehicle credentials, logs, and built installation packages are local-only and must not be committed.
